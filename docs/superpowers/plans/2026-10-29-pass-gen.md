# pass-gen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un Cloudflare Worker (Hono) que sirve un admin Angular + spartan-ng para diseñar, emitir y actualizar pases de Apple Wallet y Google Wallet, con persistencia en KV.

**Architecture:** `src/worker` contiene la API Hono (`/api/*` detrás de Cloudflare Access, `/v1/*` web service de Apple) y la lógica de firma/sync; `src/web` es una app Angular compilada a `dist/web/browser` y servida como Static Assets con fallback SPA. Todas las credenciales viven cifradas en KV.

**Tech Stack:** Hono 4, Wrangler 4, KV, node-forge (PKCS#7/PKCS#12), fflate (ZIP), WebCrypto (RS256/ES256/AES-GCM), Angular 21 (Angular 22 exige Node ≥ 22.22.3), spartan-ng 1.9 (brain + helm), Tailwind 4, Vitest + @cloudflare/vitest-pool-workers.

Spec: `docs/superpowers/specs/2026-10-29-pass-gen-design.md`.

## Global Constraints

- Un solo Worker; binding KV `PASSGEN`; secret `ENCRYPTION_KEY` (32 bytes base64); vars opcionales `ACCESS_TEAM_DOMAIN`, `ACCESS_AUD`.
- `/v1/*` sin Access (bypass), autenticado con `ApplePass <authToken>`.
- Credenciales nunca se devuelven al front.
- Tipos de pase v1: `loyalty` (Apple `storeCard`, Google `loyalty*`) y `generic` (Apple `generic`, Google `generic*`).
- Errores de API: JSON `{error, detail?}`.
- UI en español, tema spartan neutro, fuente Geist.
